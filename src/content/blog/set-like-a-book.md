Every feed shouts. A book page whispers. This blog is on the whispering side.

The landing page is plain type on warm paper. The posts are set like chapters
of a book: serif type, indented paragraphs, generous line height, and a faint
grain — the look of an e-reader screen without the glare. The list of posts is
a reading list: title, one-line note, date.

## What is on the page

- A **landing page** with just a headline and an enter link.
- A **reading list** of posts, newest first.
- **Book-style post pages** with a byline, indented paragraphs, and a Display
  panel (Paper / Dusk / Ink themes plus Light, Contrast, Warmth and Grain
  sliders) so you can tune the page to your eyes.
- **Projects** and **About** pages in the same quiet style.

Everything is plain Markdown in this repository. There is no database and no
CMS: a new post is a new `.md` file in `src/content/blog/`, and GitHub Actions
rebuilds and redeploys the site for free on GitHub Pages.
